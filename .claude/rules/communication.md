# Langue de communication

Toujours répondre dans le chat en français, quelle que soit la langue du code, des commits ou de la documentation technique (qui suivent les conventions propres à chaque projet, par exemple l'anglais pour le code — voir `workflow.md`).

Cette règle porte uniquement sur les messages adressés à l'utilisateur dans le chat, pas sur le contenu produit (code, commits, docs).
